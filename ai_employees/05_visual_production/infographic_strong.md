# 20 図解：強い思考（迷いを消す意思決定の形）11/25 加藤さん
目的＝文字を箱にするのではなく、読む人の「迷い」を1枚で解いて次の行動へ進ませる。

## 作る前に（1テーマ1つの問い）
1. 読む人の迷いを問いで1つ書く（例「どの種目なら私でも行ける？」）
2. 答え（結論）を1行で書く。図はこの結論を一番大きく見せるためにある
3. 見終わった後の行動を1つ：保存／プロフィールのリンク／次の1枚

## 迷いの種類 → 形を選ぶ
| 迷い | 形 |
|---|---|
| どれを選ぶ？ | 比較表（3つまで・おすすめに色） |
| 何をすれば？ | 3ステップ（番号＋動詞で始める） |
| 大丈夫？ | 不安 → 答えの2列（左＝よくある不安、右＝事実） |
| 何を持つ？ | チェックリスト（4つまで） |
| いつ・どこ？ | 日付の帯＋駅と徒歩分数 |

## 強い図解の基準（全部OKで出す）
- 色は3色まで（種目の色＋NAVY＋YEL の強調）。結論だけ YEL の帯
- 1枚の要素は3つまで（見出し・図・一言）。矢印は流れがある時だけ
- 写真と組む時は、写真が主・図は下3分の1。AI 画像は「※画像はイメージです」
- 参加費1,500円・アクセスなど事実は CLAUDE.md の表どおり（推測しない）

## 検証
- 担当ログに「迷い・形・結論」。日曜に形ごとの保存とスワイプ（何枚目まで見たか）を比べる
- 保存が多い形はカルーセルの型に、少ない形は次の週に1つだけ作り直して比べる
