# 成長の仕組み（LV1→100）・曜日テーマ・勝ちパターン（2026-11-11 加藤さん「神レベル運用システム v2.0」から）

番号と担当は今の33人のまま（予約・シート・指示書が全部この番号で動いているため）。v2.0 の役割は下の対応表で今の社員に持たせる。
決まり（CLAUDE.md・「加藤からの修正・決定」）は、どのレベルになっても自動では変えない。変えてよいのは「やり方」（指示書の3点セット・PATTERNS.md）だけ。

## 1. 動き方は今日から LV100、レベルの数字は「結果の段階」（11/11 加藤さん「100にすぐにしてほしい」「任せるね」）
- **動き方**：33人全員、11/11 から LV100 の動き方で動く（全員の指示書の先頭に入れた）。PATTERNS.md を読む → 目的を数字で書く → 大事な所は2案を比べる → 弱い所を3つ直す → 自己採点8点未満は作り直す → 3行で引き継ぐ。
- **レベルの数字**：動き方ではなく「会社が出した結果」で上がる。数字だけを先に100にしても中身は変わらないので、結果とずらさない。

- 会社のLVは毎晩23:55に 29 管理数値が判定し、報告の1行目に「会社LV◯（次の条件：◯◯）」と書く。

## 1.5 ⭐（星）× LV：上限なし（11/11 加藤さん「ゲームみたいに上限をつけたくない」）
- **社員**：⭐1 LV1 → ⭐1 LV100 → **⭐2 LV1** → … ⭐に上限はない。⭐が上がるほど1LVに要る EXP が増える（⭐1＝100、⭐2＝200、⭐s＝100×s）。計算は `tools/levels.py`、シート「AI社員のレベル」タブは E列の EXP を入れるだけで ⭐ と LV が自動で出る。
- **会社**：上の表（LV10〜100）を全部達成したら **会社⭐2**。⭐2 は同じ階段を、目標を1.5倍にして登り直す（リンクタップ月165・プロフィール月1,500・LINE の増加も1.5倍）。⭐3 はさらに1.5倍…と上限なし。目標は下げない（11/7 の決まり）。
- 星が上がったら：その社員の指示書の3点セットに「⭐◯で身につけた型」を1行足す（tools/build_ai_employees.py）。会社⭐が上がったら週次PDCAで全員の目標を引き上げる。

## 1.6 毎日学ぶ（学びログ）
- 毎晩23:55、その日に動いた社員は **学びを1行** 「大元の配信先」の「**学びログ**」タブに書く（日付・社員・学んだこと・根拠・次にどうするか・反映先）。**根拠のない学びは書かない**（数字か出来事）。
- 学び1行 **+5 EXP**。それが PATTERNS.md に入ったら勝ち +15／禁止 +10（GROWTH.md の1の配点）。
- 日曜の週次PDCAで、反映されていない学びを PATTERNS.md・指示書に入れ、「反映済み」に印をつける。同じ学びが3回出たら、決まり（CLAUDE.md）の変更として加藤さんに提案する（自動では変えない）。

## 5. 取り入れない・形を変えたところ（理由つき）
- **流行りの音源を使う**：API でつける音楽は権利の心配があり、Instagram の音楽ライブラリも API では選べない → 33 音楽制作の自作BGMで代える。
- **Runway・Sora・ElevenLabs など**：有料（加藤さん「無料でできる範囲」）→ 無料の画像生成・自作BGM・端末の読み上げで代える。
- **コメント・DMの自動返信（Manychat）・外部アカウントへの接触**：機械的な返信や接触はスパム判定のリスクがあり、出会いを連想させる誤解も避けたい → 返信案を出すまで。送るのは加藤さん。
- **朝〜夜の時間割で常に動く**：AI社員は予約の時刻に動く（8:00・21:00・23:55・日曜）。GitHub アクセスは1日4回まで → 朝の P は8:00、C・A は23:55にまとめる。
- **ROI・売上**：目的は公式LINEの友だち追加だけ（11/9）→ 29 管理数値はリンクタップと申込までを見る。
- **指示書の自動書き換え**：直すのは毎週日曜に1人ずつ（30 監督）。決まり（CLAUDE.md）は自動では変えない。
