## 2人に共通の決まり（軽く・止まらず）
1. **1往復で終わらせる**：Claude Code がシートと Obsidian に「そのまま使える完成品」を置く。Muse は読む→投稿→結果を書く、だけ。長い相談・壁打ちはしない。
2. **見る所は決まった所だけ**：自分のタブ（下）と Obsidian 00_Inbox の自分宛てのファイル。
3. **時間になったら投稿**：1日4回（8:30・12:30・18:30・22:30）タブを見て、予定時刻が来た「未投稿」を上から順に。
4. **中身は変えない**：おかしい時は「保留」にして L 列に1行。直すのは Claude Code。
5. **上限が来たら止める**：Muse の利用の上限に来たら、その日はそこまで。翌日の最初の回で続きから（「途中で止めた行」を L 列に書いておく）。
6. **書き込まない時間**：毎晩 23:55〜翌0:30・毎週日曜 21:00〜24:00。
7. **守ること**：顔・名前・個人情報は出さない／見ていないことは書かない／出会いを連想させる言葉は使わない／分からないことは推測しない。
8. **長い記録は書かない**：1件1ファイル・30行まで。長くなる物は Dola がいれば `80_保管（必要な時だけ）` に移す（いなければ 00_Inbox のままでよい）。80 はふだん読まない。
9. **数字の報告（11/25 変更）**：日曜18:30 の回で、自分の担当分をシートのタブ「他SNS結果」に媒体ごと1行（取れない数字は「不明」）。Obsidian には書かなくてよい。
10. **Dola がいなくても止まらない（11/25 加藤さん）**：土台は Claude Code・Muse・シート。Dola は「あれば整理が速くなる」追加。

## Claude Code からの追加の提案
1. **Muse 宛ての置き場所を名前で分ける**：Claude Code が Muse に渡すメモは `ClaudeCode_スポーツ宛_日付_内容.md`／`ClaudeCode_AI宛_日付_内容.md`。Muse は自分宛てだけ開けばよい（読む量が減る）。
2. **朝の見回りは1行で**：スポーツ用 Muse は毎朝 8:30 の回に「昨日の投稿 ◯件・保留 ◯件」を L 列か 00_Inbox に1行（失敗0を守るため）。
3. **上限の日の記録**：上限で止まった日は1行残す → 週に何回止まったかを Claude Code が見て、Muse の作業を減らす・分ける。
4. **再開の合図を決める**：止めている HP・WordPress・ビジネスプロフィールは、加藤さんが「再開」と言った日に、Claude Code が AI 用 Muse への指示を足す（それまで何もしない）。
