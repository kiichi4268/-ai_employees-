改善は「大元の配信先」の **「Instagram改善ログ」タブ** で管理する（1行＝1つの改善。ID は K-001 から順番）。
決まりは CLAUDE.md が優先。予約の作業は、このファイルとInstagram改善ログだけを読めば回せるようにしてある。

## 目標（月）と見る段（2026-11-07 加藤さん決定）
- **一番大事な数字（北極星）：リンクタップ**（プロフィールのリンクタップ＝公式LINE友だち追加とみなす）。**月110。** 達成したら上げる。**目標は下げない**（加藤さん 11/7）。今の実績は30日で41。
- **プロフィールアクセス：月1,000。** 達成したら次の月は +500（1,500 → 2,000 …）。**目標は下げない。**
- 新規参加・申込：月65〜75人（開催1回あたり5人）。数は「大元の配信先」の **「参加申込（自動）」タブ**（Googleフォームの回答タブ「スポーツイベントの参加ホーム」から、イベントごとの申込数・うち初めての人・うちInstagramで知った人を自動で数える。名前は持ち込まない）。新しい月のイベントは、このタブに行を足す（さがす言葉＝「11/14|11月14日」のように日付）。
- 保存数：1投稿100〜300。閲覧・リーチは増減だけ見る。
- **週の目標（2026-11-07 加藤さん決定。月の目標から割り出す）**：リンクタップ **週26**（110÷4.3）、プロフィールアクセス **週233**（1,000÷4.3）、新規参加は **その週の開催数×5**。前の週に足りなかった分は次の週に上乗せし、超えても次の週の目標は下げない。月の目標が上がったら週の目標も上げる（÷4.3）。「Instagram週次結果」タブのV〜Y列で自動計算。
段の順番：閲覧 → リーチ → プロフィールアクセス → **リンクタップ** → 申込・新規参加。日次・週次の「一番落ちている段」も、この順で、リンクタップに近い段から直す。
数字は `data/insights/`（毎晩23:50に自動で保存）。無いものは「不明」。

## アルゴリズムの見方（SAKIYOMI流・11/7 加藤さんの資料から）
- **北極星はリンクタップのまま**（加藤さんの決定）。そこへ届く前の「シグナル」として、次の3つを毎晩見る。
  1. **保存数**：あとで見返す価値があるか（イベント情報・まとめ・ノウハウ）。1投稿100〜300。
  2. **滞留（リールの平均視聴時間）**：最後まで見たくなる構成か。`media.csv` の ig_reels_avg_watch_time。
  3. **ホーム率**：リーチのうちフォロワーの割合。フォロワーが自分から見に来てくれているか。`account_daily.csv` の home_rate。
- いいね稼ぎ・ハッシュタグ漁り・映えだけを狙う作業はしない。情報の価値と、スワイプしたくなる流れを優先する。

## 落ちている数字 → 試す改善（毎晩・日曜に使う早見表。1回に選ぶのは1つ）
| 落ちている数字 | 試す改善の例 |
|---|---|
| 保存数 | カルーセルの情報量を増やす（持ち物・流れ・会場アクセスなど見返す情報）／最後の1枚に「保存して当日見返してね」 |
| リールの滞留 | 冒頭3秒で答えを先に見せる／1場面を短く／最後に次の開催の情報を置く |
| ホーム率 | ストーリーでフィード・リールを紹介する／プロフィールの1行目と固定投稿を見直す（変えるのは加藤さんの承認後） |
| プロフィールアクセス | 投稿の最後に「プロフィールのリンクから」を入れる／リールのキャプション1行目に申込の言葉 |
| リンクタップ | ストーリー③の誘導を強くする（初参加ガイドなど、もらえる物をはっきり）／ハイライトに申込の流れ |
| 申込 | 開催2日前〜当日のストーリーで「まだ参加枠あります」と日時・会場をはっきり |
- ストーリーの時刻（今は8:00・12:00）は、`online_followers.csv`（フォロワーがよく見ている時間帯）を日曜に見て、変えたほうがよければ加藤さんに提案する（勝手に変えない）。

## Muse（Meta の AI アシスタント）の使い方（11/9 加藤さん決定で変更）
- Muse は主役にしない。目的は2つだけ：①加藤さんの「日々のタスクの分かりやすさ」②Claude Code とは別の視点での参照（気づき）。
- 投稿・返信・夜のストーリーの中身は Muse に頼らない。加藤さんが Muse の気づきをチャットに貼ったときだけ、Instagram改善ログの根拠に使う。

## 決まり
- 同時に動かす改善は **2つまで**（何が効いたか分からなくなるため）。
- 判定は7日後か、対象の投稿が3本たまってから。数字が少ないときは「もう一週」。
- 見ていない数字・推測では判定しない（「不明」と書く）。
- **加藤さんの声かけは最優先。** Instagram改善ログに「出どころ：加藤さん」で1行入れ、次の制作から反映。「加藤からの修正・決定」にも1行。
- 良い情報（伸びた型・参考になる投稿・よくある質問）は、Instagram改善ログの「仮説」欄に根拠として書き、次の P に使う。
