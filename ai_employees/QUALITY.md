# 品質の上げ方（AI社員全員・2026-11-10 加藤さん「今は1万点の1点」）

品質を3段で測り、毎週いちばん点の低い社員の指示書（CARDS.md の3点セット）を直す。点数は「大元の配信先」の **「AI社員の成績」** タブに残す。

## 1段目：決まりを守る（機械・100点満点）
- `python3 tools/quality_check.py --since 明日の日付`（品質管理部 14〜17・30 監督が毎晩の見回りと制作の6段目で使う）
- URL・NG表現・残り人数・参加費の表記・当日の流れ（例）・会場アクセス・CTA・ハッシュタグ・素材の大きさを採点。**100点未満は出さない。** 減点には担当の社員名が出る。

## 2段目：中身の質（30 監督が採点・1投稿60点満点）
| 項目（10点ずつ） | 担当 | 10点の状態 |
|---|---|---|
| 企画 | 06・07・08 | テーマ案3つを比べ、選んだ理由が数字（保存・リンクタップ）に結びついている |
| フック | 10・12 | 1枚目・冒頭3秒・キャプション1行目で「自分のことだ」と分かる。40字以内 |
| 文面 | 11・13・16 | 1枚1メッセージ。AIっぽさ・決まり文句がない。読み手の不安に答えている |
| デザイン | 19〜22 | ブランド3色＋種目色、文字2サイズ、はみ出しなし、「どこにでもある見た目」を1つ直した |
| 音・動き | 23・33 | 声が聞き取れる、雰囲気がテーマに合う、前回と違う曲、「間」がある（リール・動画のみ。画像は企画の加点に回す） |
| **人間らしさ**（11/11） | 全員（HUMAN_CRAFT.md） | AIのテンプレート感がない：余白3割・左右どちらかに寄せた組み方・質感（finish）・言葉に具体的な場面。AIっぽい言い回し0 |
- 各項目で「何が足りないか」を1行書く。5点以下の項目は、その担当に作り直しを命じる（監督の命令役）。

## 3段目：結果（7日後・数字）
- 1投稿ごとの **リンクタップ・プロフィールアクセス・保存・（リールは）平均視聴時間** を `data/insights/media.csv` から拾う。
- 2段目の点数と結果を並べて、「点は高いのに結果が出ない」ものは採点の基準のほうを直す。

## 回し方
- **毎回の制作**：1段目100点 → 2段目を採点して担当ログに「監督：45/60（デザイン5：文字が多い→作り直し済み）」。
- **毎晩23:55**：1段目を明日の分に当てる。
- **日曜の週次**：成績タブで、2段目の項目別平均がいちばん低い社員を1人選び、その指示書の3点セット（tools/build_ai_employees.py の TOOLKIT・その社員の steps/ng）を1つ直して作り直す。直した内容は Instagram改善ログに1行。
- 点数の基準そのものも、結果（3段目）に合わせて月1回見直す。点数は上がり続けるもの、下がったら原因を書く。
