# REELS_CAROUSEL_MODEL.md — 伸びているリール・カルーセルの「型」

形（構成・見せ方）だけをまねる。他の投稿の言葉・画像・ロゴは使わない。
CLAUDE.md の絶対ルールが優先：顔は隠す／見ていないことは書かない／参加費1,500円は画像内／CTAは公式LINEの1つ／本文にURLなし／ガチ感・ナンパ連想・AIっぽい言い回しはNG。

**週1回の整理（11/15 加藤さん）**：日曜の週次PDCAで、使っていない型・古い情報・出典の長い説明を消すか短くする（質は落とさない）。消した中身は git の履歴に残る（2026-11-14 版に数字の表・出典URL・vidIQ の具体例あり）。

**狙い**：リール＝最後まで見られる・友だちに送られる／カルーセル＝保存される・2枚目でも引っかかる。

## 1. リールの型

| 型 | 形 | うちでの使い方 |
|---|---|---|
| R1 体験レポ（POV） | 「今日なにする？」→ 会場に入る → 受付 → 練習 → 試合 → 帰り道、を1〜2秒ずつ。最後に次の開催＋公式LINE。20〜45秒 | 手元・足元・シューズ・ラケット・入口・遠景だけ。全体を強くぼかす。過去の映像なら注記 |
| R2 仕事終わりの共感 | 「20:00 退勤」など社会人の場面 → 着替え・移動 → 体を動かす → 「明日もがんばれる」 | 平日夜の開催（11/26 など）の告知。効果は断定しない |
| R3 番号つきリスト（出しっぱなし） | 動きの少ない背景に番号つきの短い文10〜15行。音楽（＋読み上げ）。15〜30秒 | 「大人からスポーツを始めた人あるある」など。参加者の声は作らない |
| R4 初心者のゆる実況 | 空振りなどの動きから始め、失敗→笑い→もう一回 | 人をいじらない。了解のとれる素材だけ。無ければ AI 画像＋注記 |
| R5 Q&A・不安つぶし（11/6 の型） | 答えを先に言う → 1問3〜5秒 → 公式LINE。読み上げ＋BGM。30〜50秒 | 中身は CLAUDE.md の事実だけ。参加費は画像内にも |
| R6 情景モンタージュ＋強い一言 | 0.5〜1秒の速いカット＋0秒目の意外な一言 → 場所と日付 | 一言は事実だけ（「ラケットは借りられます」）。駅と徒歩分数 |
| R7 〇選・1項目1場面 | 最初に全部の一覧（「5/5」の札）→ 1項目＝1場面（2〜4秒・番号札＋カード）→ CTA。上にずっと同じタイトル帯（数字だけ黄色）、背景は同じ1カット、字幕2行まで・大事な言葉だけ色 | 「初参加の不安5選」「持ち物5選」「12月の開催5選」。studio/r1114/anim.html の型に帯・番号札・カードを足す |

**リール共通**
- 0秒目から動き＋大きい文字1行＋音。音なしでも文字で分かる。1画面1メッセージ。
- 大事な文字は上 約250px・下 約340px に置かない（アプリの表示で隠れる）。
- 全部声つき＋著作権フリーの曲（studio/assets/music）。
- 終わりは CTA1つ（プロフィールのリンクから公式LINE）。最後を最初につなげるとループで2回目を見てもらいやすい。
- 長さは R1・R3 は20〜30秒、R5 は45〜60秒から試し、スキップ率と見られた時間で比べる。
- 連続もの（第◯回）にして最後に次回予告もよい。会場の位置情報タグは API で付けられるか不明（要確認）。

## 2. カルーセルの型（8枚・1080×1350）

基本：1枚目＝表紙／2枚目＝もう一つの表紙（2枚目から見せ直されることがあるので、単独で分かるように）／3〜7枚目＝1枚1つ／8枚目＝まとめ一覧＋公式LINE。

| 型 | 形 | うちでの使い方 |
|---|---|---|
| C1 チェックリスト | 表紙で「何が手に入るか」→ 1枚1項目（☑）→ 最後に一覧（保存の理由） | 「バド初参加の持ち物」「当日の流れ（例）」。分からない細部は書かない |
| C2 比較・診断 | 「あなたに合う種目は？」→ 同じレイアウトで種目ごと → 早見表 | 「向いている人」は運営の考えとして書く |
| C3 不安 → 安心 | 不安を1行 → 答えを先に → 不安を1つずつ「→ 実際はこう」 | 答えは事実だけ。「浮かない」「友だちができる」は断定しない |
| C4 パノラマ | 横長の1枚を8つに切り、スワイプで「受付 → ストレッチ・基礎練習 → シャッフルゲーム → 片付け → 解散」 | AI 画像は注記、人は後ろ姿・遠景。流れは「（例）」・時間なし。文字は切れ目をまたがせない |
| C5 開催レポート（月曜） | 雰囲気の1枚＋日付・種目・会場 → 写真1枚に一言 → 次の開催・駅と徒歩分数・参加費・公式LINE | 顔は全員モザイク。写真が無ければ AI 画像＋注記。人数・盛り上がりは書かない |
| C6 番号つき「〇つのこと」 | 数字入りの表紙 → 番号ごとに1枚（位置・色をそろえる）→ 一覧 | 申込の流れなど事実のある所だけ |

**カルーセル共通**
- 1枚目は文字少なく・大きく・強い色の差。上下の端（3:4表示で切れる所）に大事な文字を置かない。
- 1枚に1つ。詰め込まない。色・番号・見出しの位置を全ページそろえる（TEAL／YEL／NAVY）。
- 最後の1枚は一覧＋CTA1つ。参加費1,500円は画像内に。

## 3. 投稿文（キャプション）の型
1. 1行目：表紙と同じことを短く。
2. 2〜4行目：要点3つまで（事実だけ）。開催があれば日付・種目・会場（駅から徒歩〇分）・参加費1,500円（当日、現金またはPayPay）。
3. 保存・送信のひと押し（出会いを連想させない）。問いかけ・コメント誘導は入れない（11/15 加藤さん）。
4. CTA1つ「参加はプロフィールのリンクから公式LINEへ」。URLは書かない。分からない点は「詳しくはDMでお気軽にどうぞ」。
5. ハッシュタグは少なめ。
