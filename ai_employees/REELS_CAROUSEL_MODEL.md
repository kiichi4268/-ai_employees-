# REELS_CAROUSEL_MODEL.md — 伸びているリール・カルーセルの「型」（2026-11-14 調べる担当）

目的：いいね・コメント・再生が多い投稿の **形（構成・見せ方）だけ** をまねる。
他の投稿の言葉・画像・ロゴはまねない・使わない。数字はすべて出典つき。出典がない数字は書かない（分からないものは「不明」）。

マカシェットの絶対ルール（CLAUDE.md）はこの型より優先する：顔は隠す／見ていないことは書かない／参加費1,500円は画像内に書く／CTAは公式LINEの1つ／本文にURLを書かない／ガチ感・ナンパ連想・AIっぽい言い回しはNG。

## 1. リールの型（6つ）

### R1. 「ひとりで行ってみた」体験レポ型（POV）
- **形**：0秒目に「今日なにする？」系の問い＋手を振る・指さす等の動き（顔なし）→ 会場に入る → 受付 → 練習 → 試合 → 帰り道、を1〜2秒ずつテンポよく。文字は大きく1行ずつ。最後は「次の開催」と「プロフィールのリンクから公式LINE」。長さは20〜45秒。
- **なぜ伸びるか**：見る人が「自分が行った場合」をそのまま想像できる。vidIQ の例では、社会人向けのフットサル交流イベントに行った体験動画（TikTok・27秒）が約110万回（その人の普段の13.3倍）、北海道マラソンの一人称の体験動画が約180万回（普段の5.7倍）。
- **マカシェットでの使い方**：顔は出さず、**手元・足元・シューズ・ラケット・会場の入口・コートの遠景**をつなぐ。全体は強くぼかす（GaussianBlur 4.6以上）。「1人参加が多い」は事実なので書けるが、その日の人数・盛り上がりは書かない。過去の映像なら「※映像は過去の開催時のものです」。

### R2. 「仕事終わりの〇〇」共感ストーリー型
- **形**：0〜2秒「疲れた／20:00 退勤」など“よくある社会人の場面”（時刻テロップ＋ため息の手元）→ 着替え・移動 → 体を動かす → 「明日もがんばれる」で終わる。BGMは最初から鳴らす。読み上げは短く。
- **なぜ伸びるか**：働く20〜40代が「わかる」と思い、同じ立場の友だちに送りたくなる（＝送信）。vidIQ の例では、会社員の仕事帰りの一人焼肉を時系列で見せたリールが約36.5万回（普段の98.7倍）。
- **マカシェットでの使い方**：平日夜開催（例：11/26(木)18:00-21:00 まもりやまテラス、新代田駅から徒歩約5分）の告知に使う。「ストレス発散になる」等の効果は断定しない。「仕事帰りにちょっと体を動かしたい人へ」まで。

### R3. 番号つきリスト「〇〇な人がわかること・あるある」型
- **形**：背景は動きの少ない1カット（シャトル・ボール・体育館の床）、上に**番号つきの短い文が10〜15行**ずっと出ている。音楽だけ（または読み上げ＋音楽）。キャプションで「何番が当てはまる？」と聞く。ループする長さ（15〜30秒）。
- **なぜ伸びるか**：一時停止して全部読むので見られる時間が伸び、何回も見返される。番号を聞くのでコメントが来る。vidIQ の例では「社会人になってわかったこと」を番号リストで出しただけのリールが約110万回（普段の93.5倍、フォロワー1.3万人）。
- **マカシェットでの使い方**：「大人になってからスポーツを始めた人あるある」「1人参加の前に心配だったこと」など。中身は加藤さんから聞いた事実・よくある質問だけで作る（参加者の声を作らない）。顔は出ない構成なのでそのまま使える。

### R4. 「初心者 × ちょっとした失敗」ゆる実況型
- **形**：最初の1秒で「ラケットを振る→空振り」などの動き。短い場面をどんどん切り替え、失敗→笑い→もう一回、で終わりは「また来週もやる」。文字は会話の吹き出しっぽく。
- **なぜ伸びるか**：「下手でも楽しそう」が伝わり、ガチ感が消える。vidIQ の例では、ピックルボールで初心者が挑戦する短い動画が約180万回（普段の33.6倍、フォロワー5,100人）。小さいアカウントでも当たる型。
- **マカシェットでの使い方**：顔は出さない（後ろ姿・足元・シャトルの軌道）。**人をいじる・馬鹿にする笑いはしない**。スタッフ（運営側）の空振りなど、本人の了解がとれる素材だけ。素材がなければ AI 画像のイメージ動画＋「※画像はイメージです」。

### R5. 結論先出し「Q&A・不安つぶし」型（11/6「1人参加Q&A」の発展）
- **形**：0〜1秒で答えを先に言う（例：「1人参加、大歓迎です」）→ よくある質問を1問3〜5秒でテンポよく（道具は？ 初心者でも？ いくら？ 当日の流れは？）→ 最後に公式LINE。読み上げ＋BGM。長さ30〜50秒。
- **なぜ伸びるか**：最初の3秒で「自分に関係ある」と分かるとスキップされにくい。最後まで見ると不安が消えて行動（リンクタップ）につながる。長さは Socialinsider で一番再生が多い45〜60秒の帯に近い。
- **マカシェットでの使い方**：中身は CLAUDE.md の事実だけ（参加費1,500円・当日現金かPayPay／ラケット貸出あり（バド・卓球）／初心者7割・経験者3割くらい／当日の流れは「（例）」で時間なし）。参加費は画像内にも出す。

### R6. 情景モンタージュ＋「1つだけ違う」強い一言型
- **形**：体育館・コート・道具のきれいな映像を音楽に合わせて素早く切る（1カット0.5〜1秒）。0秒目に意外な一言を大きく（例のツールでは登山動画の「クマがいない」）。最後に場所と日付をまとめる。
- **なぜ伸びるか**：動きと音で最初の1秒に止まる。意外な一言で「え？」となり続きを見る。vidIQ の例では初心者向けの山の紹介が約70万回（普段の3.7倍）。
- **マカシェットでの使い方**：一言は事実だけで作る（例：「ラケットは借りられます」「1人参加がほとんど」）。会場紹介＋最寄り駅と徒歩分数（分かる会場だけ）。人が写る場面はぼかし。

### リール共通のルール
- **最初の1秒**：止まった画面で始めない。動き＋大きい文字1行＋音を0秒目から。音なしでも文字だけで分かるように。
- **文字**：1画面1メッセージ。上下の端（UIで隠れる所）には置かない。
- **音**：読み上げ＋BGM（CLAUDE.md：リールは全部声つき）。曲は studio/assets/music の著作権フリー曲。
- **終わり方**：CTAは1つ「プロフィールのリンクから公式LINEへ」。最後の画面を最初の画面につなげる（ループ）と2回目を見てもらいやすい。
- **長さ**：まずは R1・R3 は20〜30秒、R5 は45〜60秒で試し、インサイトの「スキップ率」と「見られた時間」で比べる（どの長さが一番かは、調べた範囲では出典どうしで食い違う＝不明）。

## 2. カルーセルの型（6つ）

基本の枠（8枚・1080×1350）：**1枚目＝表紙／2枚目＝もう一つの表紙／3〜7枚目＝1枚1つのこと／8枚目＝まとめ＋公式LINE**。
2枚目は「見せ直し」で最初に出ることがあるので、**2枚目だけ見ても意味が分かる**ように作る。

### C1. チェックリスト型（保存狙いの王道）
- **1枚目**：「初めての〇〇 持ち物チェックリスト」など、**何が手に入るか**を1行で。文字は大きく、少なく、背景とはっきり差をつける。
- **2〜7枚目**：1枚に1項目（☑＋短い説明）。
- **8枚目**：全部を1枚にまとめた一覧（ここをスクショ・保存してもらう）＋公式LINE。
- **なぜ伸びるか**：「あとで使う」から保存される。日本の運用解説（OWNLY・s--line・ADDness）でも、手順・チェックリスト・比較は保存されやすい型として挙がる。
- **マカシェットでの使い方**：「バド初参加の持ち物」「当日の流れ（例）」など。事実だけ（ラケット貸出あり・参加費1,500円・受付で参加受付証を見せる）。持ち物の細部で分からないものは書かない。

### C2. 比較・診断型（「あなたはどっち？」）
- **1枚目**：問いかけ（「あなたに合う種目は？」）＋4種目の色（バド緑・バレー橙・卓球/野球青）。
- **2〜7枚目**：同じレイアウトで種目ごとに「こんな人向け・人数・会場までの近さ」を並べる。最後の方に早見表。
- **8枚目**：「気になる種目の日程は公式LINEで」。
- **なぜ伸びるか**：比べる表は保存され、「あなたは〇〇っぽい」と友だちに送られる（送信）。キャプションで「何タイプでした？」と聞けばコメントも来る。
- **マカシェットでの使い方**：「向いている人」は運営の考えとして書き、参加者の感想に見せない。11/12予定の「あなたに合う種目は？」をこの型で作る。

### C3. 不安 → 安心（ビフォー・アフター）型
- **1枚目**：よくある不安を大きく1行（「1人で行って浮かない？」）。
- **2枚目**：答えを先に（「ほとんどが1人参加です」）。
- **3〜7枚目**：不安を1つずつ「→ 実際はこう」で解く（初心者7割・経験者3割くらい／ラケット貸出／当日の流れ（例））。
- **8枚目**：まとめ＋公式LINE。
- **なぜ伸びるか**：自分の気持ちを言い当てられると止まる。ビフォーアフター型は保存されやすい型として ADDness が挙げている。
- **マカシェットでの使い方**：答えは CLAUDE.md の事実のみ。「浮かない」「友だちができる」は断定しない（見ていないこと）。

### C4. 横につながるパノラマ型
- **形**：1枚の横長の絵（体育館のコートなど）を8つに切り、スワイプすると線や道がつながって続く。進むごとに「受付 → ストレッチ・基礎練習 → シャッフルゲーム → 片付け → 解散」が現れる。
- **なぜ伸びるか**：「次が見たい」で最後までスワイプされる（Meta はスワイプ数と見た枚数を見ている）。
- **マカシェットでの使い方**：AI画像なら「※画像はイメージです」、人は後ろ姿・遠景のみ。流れには「（例）」を付け、時間は書かない。文字は各枚の中央80%に収める（切れ目に文字をまたがせない）。

### C5. 開催レポート「写真ダンプ＋一言」型（月曜のレポート）
- **1枚目**：一番雰囲気が伝わる1枚（道具・会場・遠景）＋日付・種目・会場名だけ。
- **2〜7枚目**：写真1枚に短い一言（事実：何をしたか・会場の様子）。
- **8枚目**：次の開催日＋最寄り駅と徒歩分数＋参加費1,500円＋公式LINE。
- **なぜ伸びるか**：運動クラブの事例（Sol Run Club など）では、集合写真やアルバムを参加者が自分でシェアして広がっている。
- **マカシェットでの使い方**：顔は全員モザイク。当日の写真がなければ AI 画像＋「※画像はイメージです」。人数・盛り上がりは書かない。

### C6. 番号つき「〇つのこと」まとめ型
- **1枚目**：数字入りの表紙（「大人の初参加で知っておくと楽な5つのこと」）。数字は大きく。
- **2〜7枚目**：番号ごとに1枚。番号の位置・色は全部そろえる。
- **8枚目**：5つを1枚に一覧＋公式LINE。
- **なぜ伸びるか**：数字で「何枚あるか・何が分かるか」が先に見えるので、スワイプしてもらいやすい。最後の一覧が保存の理由になる。
- **マカシェットでの使い方**：中身は申込の流れ（プロフィールのリンク → 公式LINE → イベントカレンダーから予約 → 参加フォーム → 合言葉をLINEに送る → 参加受付証）など、事実のある所だけ。

### カルーセル共通のルール
- 1枚目：文字は少なく・大きく・強い色の差。**何がもらえるか**を言う。上下の端（3:4表示で切れる所）に大事な文字を置かない。
- 2枚目：もう一つの表紙として単独でも分かるように。
- 1枚に1つのこと。詰め込みすぎない（詰め込み・最後にCTAがないのは保存されない典型、ADDness）。
- 色・番号・見出しの位置を全ページそろえる（TEAL／YEL／NAVY）。
- 最後の1枚：一覧（保存する理由）＋CTA1つ（公式LINE）。参加費1,500円は画像内に。

## 3. 投稿文（キャプション）の型

1. **1行目**：表紙と同じことを短く（フィードで最初に見える所。ここで続きを読むか決まる）。
2. **2〜4行目**：中身の要点を3つまで（事実だけ）。開催があれば「日付・種目・会場（最寄り駅から徒歩〇分）・参加費1,500円（当日、現金またはPayPay）」。
3. **問いかけ1つ**：「何番が当てはまりますか？」「何タイプでした？」（コメントの入口）。
4. **保存・送信のひと押し**：「当日見返せるように保存しておいてください」「気になっている友だちに送ってみてください」。※出会いを連想させない。
5. **CTA1つ**：「参加はプロフィールのリンクから公式LINEへ」。URLは書かない。分からない点は「詳しくはDMでお気軽にどうぞ」。
6. ハッシュタグは少なめ（効果の数字は今回は不明）。
