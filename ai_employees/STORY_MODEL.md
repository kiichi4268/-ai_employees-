# ストーリーの見本（11/13 加藤さん「閲覧が毎回1,000を超えるストーリーを真似して」）

毎晩23:55に明日の 10:00・19:00 を作るとき、このページを最初に読む。中身はマカシェットスポーツのイベントのまま、**見せ方の「型」だけ**をまねる（他のアカウントの文・写真・ロゴは使わない）。

## 1. 見本の集め方
- 他のアカウントの閲覧数は外から見えない（ストーリーの閲覧数は持ち主しか見られず、24時間で消える）。だから「1,000超え」は次の3つで代わりに見る。
  1. **フォロワーの多いスポーツイベント・リーグ・大会の公式アカウント**の型（公開記事・ハイライトで確かめられるもの）
  2. **加藤さんが「いい」と思ったストーリーのスクショ**（チャットに貼ってもらう。型を書き出してここに足す）
  3. **自分たちのストーリーで閲覧が一番多かった回**（data/insights から。1,000 を超えたものは必ずここに足す）

## 2. 今わかっている、閲覧が伸びる型（公開されている記事から）
| 型 | 中身 | 自動（API）でできるか |
|---|---|---|
| 前と後で見せる | 開催の前（会場の準備・道具・カウントダウン）と後（片付け・会場の静けさ）を続けて見せる | できる |
| 毎日同じ時間に出す | 1日1回以上、決まった時刻に出す。見る人が「いつもの」と思える | できる（8・10・12・19時） |
| 型をテンプレートにする | 良かった組み方を保存して何度も使う | できる（make_week3.py） |
| 参加型スタンプ | 投票・質問・クイズ・カウントダウン | **できない（夜の手動だけ）** |
| 開催まで何度も告知 | 告知は1回で終わらせず、開催日まで続ける | できる |
| ハイライト・リールに回す | 良かったストーリーをハイライトやリールにも使う | ハイライトは加藤さんの手動 |

## 3. 10:00・19:00 で試す順番（1日1つ）
1. 1枚目の見出しを「問いかけ」にする（例：「今週末、空いてる？」）
2. 1枚目を「開催まであと◯日」のカウントダウン型にする
3. 2枚目の動画を、道具・会場のアップから始める（最初の1秒で何のスポーツか分かる）
4. 3枚目の QR の見出しを時刻に合わせる（10時＝「今日の予定に」、19時＝「仕事帰りに」）
5. 文字を減らす（1枚に1つのことだけ）
- 良かった型は残し、悪かった型は戻す。3回続けて良ければ 8:00・12:00 にも広げる（ig-daily-pdca 4.9）。

## 4. vidIQ で見つけた「伸びている型」（11/13・日本・社会人・スポーツ／イベント・平均の4〜180倍伸びた投稿）
※ vidIQ はリール・TikTok の数字。ストーリーの数字は取れないので、最初の1秒の作り方と文の型だけを借りる。
| 型 | 例（伸び方） | うちでの使い方（顔は出さない） |
|---|---|---|
| 最初の1秒で「だれの話か」を文字で出す | 「限界社会人1年目」（平均の4倍） | 1枚目の見出しを「仕事帰りの社会人へ」「運動不足の社会人へ」に |
| 「◯◯3選」＋「保存して」 | 「1日で取れる国家資格3選」（183倍）、「屋内アクティビティ7選」（6倍） | 「1人参加でも安心な理由3選」「持ち物3選」→ 保存を誘う |
| 体験の一言から始める | 「人生初フットサル楽しかった」（13倍） | 「人生初バレー、どう？」の問いかけ＋道具・コートの映像 |
| 社会人あるある | 「会社のスポーツ大会で…」（4倍） | 「最後に運動したの、いつ？」など（ガチ感・ナンパ連想は出さない） |
| 最初の1秒で動く映像 | ボールが飛んでくる・ゴールのアップ | ②の動画をシャトル・ボール・ネットのアップから始める |
- 出会い・マッチングアプリ系の型は使わない（CLAUDE.md の NG）。

## 5. vidIQ の使い方（ルール）
- **見るだけ**。vidIQ の投稿・予約・コメント返信の機能は使わない（投稿は PR の Merge だけ）。
- クレジットは月150（12/13 に戻る）。outlier 検索1回5。**週次PDCA（日曜）で2回まで**＋加藤さんに頼まれたとき。使った回数を報告に書く。

## 6. 加藤さんが選んだ見本アカウントから学ぶ「作り方」（11/13）
**11/13 加藤さん：見本にするのは作り方だけ。書いてある中身（言葉・主張・ルール・特徴）は全部使わない。** 中身は今まで通りマカシェットスポーツの事実だけ（CLAUDE.md）。
見本：@hoistle_futsal・@hoistle_volleyball・@hoistle_badminton・@hoistle_utsunomiya・@calcio__2020・@emu_futsal・@laughter__sports（vidIQ でリール各12本の組み立てを見た。ストーリーは外から見られない）。

### 作り方の型
| 作り方 | 中身 |
|---|---|
| 1行目の置き方 | 1行目は見る人の頭の中の声（不安・本音・問い）を「」で置く。説明は2行目から |
| 長さ | 動画は短く（7〜25秒）。伸びている投稿ほど短い |
| 1本1場面 | 1本の動画は1つの場面だけ。そこに文字は1行 |
| シリーズ化 | 1つのテーマを、種目を替えて同じ形で続けて出す |
| 問いかけ | 2択で聞いて、次の1枚で答え（開催日など）を見せる |
| だれ向けかを先に | 1行目で「だれに向けた話か」を言い切る |
| 終わり方 | 最後は毎回同じ形の1行で、公式LINEへ |
| 毎回の変化 | 毎回同じ文の繰り返しは伸びていない → 形は同じ、言葉は毎回変える |

### 10:00・19:00 で試す順番（1日1つ）
1. ①の1行目を「」の問い・本音にする
2. ②の動画を1場面・7〜10秒・文字1行にする
3. 同じ形を種目を替えて続ける（その週に開催がある種目）
4. 2択で問いかけ、③で答えを見せる
5. 1行目で「だれ向けか」を言い切る
- 言葉はマカシェットの事実から作る（参加費・会場・1人参加・初心者7割くらい など）。見本アカウントの言葉・主張は使わない。顔は出さない。
