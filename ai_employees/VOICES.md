# VOICES.md — 参加者の生の声（つなげーとのレビュー）

元：Obsidian `01_Strategy_Projects/つなげーと_レビュー（生の声）.md`（本文26件・開催ごと。11/18 加藤さん）。追加とレビューへの返信は Muse。Claude Code は日曜21:00 に読んでここを更新する。

## 使うときの決まり（CLAUDE.md の「事実」と同じ考え）
- 言葉は変えない（要約しない・言い換えない）。名前・ニックネームは出さない。
- 必ず「つなげーとのレビューより」と出どころを添える（画像内かキャプション）。
- 他の開催の声と混ぜない。件数・評価（4.7 など）を出すときは、その日に確かめた数だけ。
- 「初参加率85%以上」「1人参加が半数以上」は出どころ不明のため使わない（「ほとんどが1人参加」「初心者7割・経験者3割くらい」を使う）。
- 出会いを連想させる使い方はしない（「男女ともにちょうどよく」は使わない）。

## 使える一言（場面ごと）
| 一言（そのまま） | 合う場面 |
|---|---|
| 「内輪ノリとかチャラい感じもなく安心しました」 | 不安つぶし（ストーリー①・リール R5 のフック・カルーセル C3） |
| 「気がついたら自然と笑顔になれました」 | 雰囲気（カルーセルの表紙・レポート） |
| 「同じように1人の参加の方がいて」 | 1人参加の安心（19:00 の仕事帰り枠） |
| 「回転率も良かったので人数は多かったですが、待つ時間もあまりなく」 | 運営の設計（初心者向け・当日の流れ（例）） |
| 「在宅勤務で鈍った身体解すのにバドミントンは丁度よかったです」 | 動機（平日夜の開催の告知） |
| 「ルールやコツなど教えてくださる人が多くて楽しかったです」 | 初心者向け（バド） |
| 「勝ち負けにこだわるような方は向いてないかも」 | ゆるさの証拠（経験者向けの一言として） |

## 勝ちパターン（分析）
① 初心者・おひとり様がすぐ馴染める温かい空気 ② 運営がペア・組み合わせを考える「設計されたエンジョイ空間」 ③ 動機は運動不足・リフレッシュ、得られるのは心地よい汗と会話。トーンは「ゆるく楽しく、でもしっかり動ける」。
