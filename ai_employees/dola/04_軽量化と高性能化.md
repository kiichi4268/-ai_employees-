# Dola 2人を軽く・強く使う決まり（11/26）
## 軽くする（ムダを出さない）
1. 1回1枚・20行まで。長くなる物は 80_保管 へ置き、まとめには1行だけ
2. 読むのは「今日増えた物」だけ（前に読んだ物は読み直さない）。保管庫の全部を読むのは第1日曜だけ
3. 数字は書き写すだけ（考えない）。考えるのは Claude Code
4. 前の日と同じことは書かない（「変わりなし」の1行でよい）
5. Claude Code が読むのは Dola2 の1枚と、日曜の Dola1 の1枚だけ（3つのタブを読まない分、軽くなる）

## 強くする（質と数字に効かせる）
1. 書く物は毎回同じ型（番号と見出しを固定）→ 速く読めて比べられる
2. どの行も「数字」か「出どころ」をつける（推測の行を作らない）
3. 毎回「次に動く1つ」を最後に書く（誰が・何を）
4. 勝ちパターンは数字で伸びた物だけ入れる（気分で入れない）
5. 止まっている所は3日で必ず一番上に上げる（埋もれさせない）

## 2人の成績（日曜に Claude Code が1行）
- Dola1：勝ちパターンが次の制作に使われた数・80_保管へ移した数・重なりの数
- Dola2：問い合わせの返事漏れ0か・まとめが毎晩出たか・ペース警報が当たったか
