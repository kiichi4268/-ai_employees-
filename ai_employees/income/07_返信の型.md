# 返信の型（Muse が「この文で返す」）ClaudeCode_AI宛_返信の型 の元・11/26 夜
| 質問 | 返す文 |
|---|---|
| どんな投稿を作れますか？ | ストーリー・リール・カルーセルを、写真と文字と短い動画で作ります。見本は出品ページの画像をご覧ください。 |
| 写真がありません | 少なくても大丈夫です。文字と図の投稿から始めて、写真が届いたら足していきます。 |
| いつから始められますか？ | ご注文から3日ほどで最初の下書きをお送りします。日にちのご希望はお聞きして決めます。 |
| フォロワーは増えますか？ | 必ず増えるとはお約束できません。毎週数字を見て、1つずつ直していきます。 |
| 中身は確認できますか？ | 出す前の下書きを毎週お送りします。直したい所は何度でもお申し付けください。 |
| 値段を安くできますか？ | → 返さずに「加藤さん確認」（値段は加藤さんが決める） |
| 注文したい・契約したい | → 返さずに「加藤さん確認」 |
| 上に無い質問 | → 返さずに「加藤さん確認」 |
- 最後に必ず「ご質問ありがとうございます。」で始め、「よろしくお願いいたします。」で終える
