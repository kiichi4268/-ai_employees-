# 音楽の設計（11/27 加藤さん「Claude Code 側で考えて」「曲は無料の方法で」・完成度1）
## 曲の作り方（無料・権利がこちらにある順）
1. **audio.py の bgm()（その場で作曲・無料・回数無制限）**：雰囲気（happy／gentle／fresh／pop）× seed で毎回違う曲。ストーリーの②に 11/27 の夜の回から混ぜる
2. **vidIQ の曲**：使わない（11/27 加藤さん「無料の方法で」）。今ある4曲はそのまま使う
3. ACE-Step 等のローカル作曲：11/25 加藤さん「不要」→ 使わない
4. **使わない**：人気の曲そのもの（自動投稿は Instagram の音源ライブラリを付けられない・権利が無い）

## 回し方（時間帯 × 日替わり・tools/audio.py music_for）
| 時間 | 雰囲気 | 候補 |
|---|---|---|
| 8:00 | 明るい朝 | acoustic_morning・pop_bright＋bgm(fresh) |
| 10:00・12:00 | ポップ | pop_bright・citypop_night・acoustic_morning＋bgm(happy) |
| 15:00 | やわらかめ | acoustic_morning・lofi_evening＋bgm(gentle) |
| 19:00 | 落ち着いた夜 | lofi_evening・citypop_night |
- リールは声が主役：声の間だけ曲を下げる（ダッキング）を 12/1 の制作から
- 曲ごとに「最後まで見た率」を記録（Dola2 が表に・日曜に Claude Code が判定）。負けた曲は外す

## 人気の曲の使い方
- Muse が集めた人気の曲は「雰囲気の言葉」だけ使う（テンポ・楽器・明るさ）→ bgm() や vidIQ の指示にする。曲そのものはまねない

## 収益化の可能性（要確認のまま進めない）
- 作った曲の販売・素材化：vidIQ の曲の規約で再販売できるか要確認。bgm() の曲はこちらの物なので、まとめて素材にできる
- マカスポくんの「テーマ曲」：スタンプ・YouTube の顔と組み合わせて覚えてもらう（12月に案）
