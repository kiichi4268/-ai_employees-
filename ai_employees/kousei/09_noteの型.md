# note の型（メイン・AI 共通・11/28 加藤さん「目次・トップ画像・間に画像と動画」）
**毎日出す。目標＝いいね・スキ（ハート）が前日の記事より多いこと**（Muse の速報で比べ、負けた日は次の記事でトップ画像か題を1つ変える）
## 1本の形（上から順に・無料も有料も同じ）
1. **トップ画像**（1280×670）：写真台帳の Nt から1枚＋見出し1行。無ければ図解（AI 画像なら※画像はイメージです）
2. **導入3行**：誰の・どんな悩みか → この記事で分かること
3. **目次**：見出し（##）を3〜5個。note の「目次」機能をオンにする（Muse）
4. **本文**：見出しごとに「文 → 画像か動画1つ」をくり返す。**300字ごとは目安**（固定しない。読みやすさで前後してよい）
   - 画像：現場の写真（顔なし）・図解（数字の前後・手順）・スクショ（数字の画面は個人名を消す）
   - 動画：Instagram のリール・ストーリー②を YouTube に上げた物を貼る（15〜30秒）
5. **まとめ3行＋次の1つ**
6. **最後の1行（CTA は1つ）**：メイン＝公式LINE（https://lin.ee/QuIhlkl）／AI＝ココナラか有料記事
