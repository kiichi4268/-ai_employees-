# vidIQ の使い方の決まり（Claude Code・加藤さん向け・11/27）
- クレジットは全部の道具で共通。11/26 時点で残り5（曲1つ25）→ **曲は止まっている**
- 使う順（高い物ほど後）：①見るだけの調べ物（伸びている投稿・アカウント）週2回まで ②曲（クレジットがある時だけ・1回に4曲まで）③画像・動画の生成は使わない（Claude Code と加藤さんの写真で足りる）
- 曲の指示は「ジャンル＋雰囲気＋楽器＋テンポ」。人気の曲の名前は書かない（雰囲気の言葉だけ）
- できた曲は studio/assets/music に名前をつけて置き、04_音楽.md の表に足す
- 足りない時：加藤さんに「足す／待つ」を1行で聞く（勝手に買わない）
