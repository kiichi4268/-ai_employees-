# 11月 投稿表（手動運用版）

11月は手足（Claude Code）の自動投稿が間に合わないため、脳（チャット）が文章を作り、貴一さんの承認後に貴一さんがアプリで投稿・予約投稿します。設計書のルール（CTAは1つ・参加費表記・NG表現）はそのまま使います。

## 毎日の流れ

1. 毎晩23:45：チャットに翌日分の確認セットが届く（フィード／リールの文章、ストーリーズ3本の文章）
2. 貴一さんが「OK」か、番号つきで修正を返す
3. 承認後、貴一さんがInstagramアプリで投稿・予約投稿する（音楽・LINEリンクスタンプもアプリで付ける）
4. 開催当日の夜：その日のフォルダに写真と一言メモを入れる → 翌日レポートの文章を作る

**投稿の型（次回分から）**：ストーリーは朝・昼・晩それぞれ3つセット（1日9本）（画像・動画・投票などの仕掛け）、カルーセルは8枚（1枚目表紙〜8枚目まとめ・CTA）、リールは長さ自由。毎回テーマ案を3つ出してから作ります。詳しくは 投稿企画（型とテーマ案）

## ルールBの代わり（返信がない日）

- 承認のない投稿は出さない
- そのかわり、開催日の「当日募集」は2日前の確認セットに先に入れて承認をもらう（前日リールと同じ夜に承認）。これで前夜に返信がなくても当日募集は出る
- 満員・中止になったら一言もらえれば満員版に差し替える（差し替えは貴一さんがアプリで行う）
