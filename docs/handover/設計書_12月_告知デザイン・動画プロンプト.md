## 1. 告知画像のデザイン構成

### キャッチコピー（A/Bで比べる）

- **A案（メイン）**：「12月は全10回！ 今年のしめくくりは、体を動かそう」
- **B案**：「年末の運動不足、みんなで解消！」
- サブコピー（共通）：「初心者・1人参加 大歓迎｜上手さより楽しさ重視」
- NG：クリスマスの「出会い」を連想させる言い方（12/24は「クリスマスイブも体を動かそう」程度にとどめる）、ガチ感や初心者お断りに見える言い方

### 色・フォント・雰囲気

| 項目 | 指定 |
| --- | --- |
| ベース色 | 紺 #142A5C（背景の暗い部分・文字）／白 #FFFFFF（カード） |
| アクセント | 青緑 #18A0B2（見出しの筆の帯）／黄 #FFEC1E（強調・「全10回」） |
| 種目の色 | バドミントン 緑 #2E9646／卓球 赤 #E23C3C／バレー オレンジ #F38020／野球 青 #2F6FD1 |
| 12月らしさ | 白い小さな雪の粒・キラキラを背景にうっすら（不透明度20〜30%）。赤・緑のクリスマス色は使いすぎない |
| フォント | 見出し：Noto Sans JP Black（少し斜め・白ふち）／本文：Noto Sans JP Bold。Canvaなら「Noto Sans JP」で揃う |
| 背景 | 実際のイベント写真をぼかして紺を重ねる（暗くする割合 40〜50%）。顔が写る場合は必ずモザイク |
| 雰囲気 | 明るくて親しみやすい。「年末のゆるいイベント」感。密度は詰めすぎず、文字は大きく |

### BGMの提案

| 項目 | 提案 |
| --- | --- |
| ジャンル | 明るいポップ／フューチャーベース（リール向き）、アップテンポのアコースティックポップ（フィードの動画向き） |
| テンポ | 120〜128 BPM。映像の切り替えを拍に合わせる（種目の切り替え＝2拍と4拍ごと） |
| 雰囲気 | はずむ、前向き、少しだけ冬らしい鈴の音。声を重ねるので、歌なし（インスト）か、声が小さい曲 |
| 音量 | ナレーションを入れるならBGMは約20〜30% |
| 注意 | Instagram・TikTokのアプリ内の音楽か、商用利用OKの曲だけを使う |
