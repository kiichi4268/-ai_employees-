## 毎日の流れ

迷ったら、①プロフィール → LINE、②必須3点セット、③ストーリーズ毎日3本、④保存狙いの投稿、の順で優先します。

**① プロフィール → LINE（毎日・常時）**

- プロフィールのリンクを公式LINE（https://lin.ee/WIbLPFV）にする
- 晩のストーリーズに毎日LINEのリンクスタンプを付ける（プロフィールを通らずにLINEへ）
- 全投稿のCTAは1つだけ：「LINEで初参加ガイドを受け取る」。開催直前は「LINEのEVENTから予約」
- 固定投稿とハイライトは #9 が月1で点検

**② 必須3点セット（開催ごと・絶対）**

| タイミング | 形式 | 中身 | 止める条件 |
| --- | --- | --- | --- |
| 開催前日 | リール | 明日の種目・時間・会場・残り枠 → LINEで予約 | 満員・中止なら満員版 |
| 開催当日（時間は不明・仮で10:00） | フィード | 通常版「まだ参加者募集中！」／満員版「次は〇日の〇〇へ」 | 状態で版を選ぶ |
| 開催翌日 | カルーセル | 開催レポート（実写＋一言メモ）→ 次回告知 → LINE | 素材フォルダが空なら「素材待ち」 |

- 同じ日に2開催：当日の募集は1本にまとめ、レポートは開催ごと
- 連日開催：「翌日レポート」と「当日募集」が同じ日に重なってよい

**③ ストーリーズ（毎日3本）**

| 枠 | 時間 | 中身 |
| --- | --- | --- |
| 朝 | 8:00 | 今日・今週の開催と残り枠 |
| 昼 | 12:00 | 安心材料（初参加の声・Q&A・雰囲気） |
| 晩 | 平日20:00／金・土21:00 | 一番大事な内容＋LINEリンクスタンプ |

**④ 保存狙い・月の区切り**

- 月初にリール「今月の日程」、月末にリール「今月の振り返り」
- 開催がない週は保存狙いのカルーセルを1本（本数はAIの提案。実績で見直す）

## 承認ルール

毎晩23:45に翌日分をまとめて確認し、承認されたものだけを手足が投稿します。いまは承認ありで運用し、「認証不要」と伝えたら外します。

1. 23:45に、翌日分の確認セットが届く（開催日は通常版と満員版の2種類）
2. 貴一さんは「OK」か、番号を指定して修正を返す
3. 承認されたものだけを手足へ渡す

| 場面 | 動き |
| --- | --- |
| 朝8:00までに返信がない | ルールB：開催日の定型告知だけ出す。満員・中止の募集投稿は出さない。それ以外は止める |
| 急な変更（満員・募集中止） | 「1107バド満員、1110へ誘導」と一言 → 承認済みの満員版に切り替え |
| 承認後に人数が変わった | 数字だけシートの実数で差し替え（文章は変えない） |
| 人数が「不明」 | 人数を投稿に書かない |

返信の例：「OK」／「②の通常版、絵文字を減らして」／「満員版にして、誘導先は11/7」
