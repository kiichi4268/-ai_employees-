# 投稿企画（ストーリー3つ・カルーセル8枚・リール）

11月から、企画はこのタブの型で作ります。毎回テーマ案を3つ出し、選んだテーマで「ストーリー3つセット」「カルーセル8枚」「リール（長さ自由）」を作ります。

## 投稿の型（ルール）

| 形式 | 決まり |
| --- | --- |
| ストーリー | 朝・昼・晩それぞれ3つセット（1日9本）。各セットは1枚目＝画像（静止画）／2枚目＝ショート動画／3枚目＝投票・クイズ・質問・リンクなどの仕掛け |
| カルーセル | 1投稿8枚。1枚目＝表紙、8枚目＝まとめ・CTA。各スライドの文字とデザインを指示する |
| リール | 枚数・長さの決まりなし。目的に合わせて最適な長さと構成にする |

共通ルール：参加費は「1,500円（当日、現金またはPayPay）」。顔は隠す。ガチ感・初心者お断りに見える表現・ナンパを連想させる表現は使わない。分からないことは「不明」と書く。

## 投稿テーマのアイデア（11月）

1. **はじめての1人参加ガイド**（おすすめ）：「1人で浮かない？」「ついていける？」などの不安を先に答える。保存されやすく、公式LINEの特典『初参加ガイド』へそのままつなげられる
2. **あなたに合う種目は？ 11月の種目えらび**：バド・バレー・卓球・野球を「運動量」「道具の貸出」「会場の行きやすさ」で比べる。投票やクイズと相性がよい
3. **数字で見る参加者のリアル**：20〜40代、1人参加が多数、初心者7割・経験者3割くらい、など実際の数字で安心してもらう

以下は1の「はじめての1人参加ガイド」で作った構成案です。

## カルーセル（8枚）

サイズ1080×1350。色は紺・青緑・黄色、太いゴシック体。全スライド右下に @macachette\_sports。

| 枚 | 文字 | デザイン指示 |
| --- | --- | --- |
| 1枚目（表紙） | 「はじめての社会人スポーツ 1人参加ガイド」／小見出し「保存して当日見返してね」 | 体育館の写真を大きく（顔はぼかす）。タイトルは黄色の筆の帯、「保存」の文字に赤い小さなラベル |
| 2枚目 | 「よくある不安 3つ」①1人で浮かない？ ②運動不足でもついていける？ ③何を持っていけばいい？ | 白いカード3枚を縦に並べ、番号を青緑の丸で。「次のページで答えます→」 |
| 3枚目 | 「どんな人が参加してる？」20〜40代の社会人／1人参加が多数／初心者7割・経験者3割くらい | 数字を大きく見せる3つのブロック。人物はイラスト（実写なら顔をぼかす） |
| 4枚目 | 「申し込み〜当日の流れ」①公式LINEに登録 ②イベント参加フォームで申し込む ③表示された合言葉をLINEに送ると参加受付証が届く ④当日、受付で見せるだけ | 4ステップを矢印でつなぐ。③に受付証の見本画像を小さく入れる |
| 5枚目 | 「持ち物」着替え・体育館シューズ・飲み物／バドミントンはラケット貸出あり | 持ち物のアイコンを3つ並べる。貸出は黄色のラベルで目立たせる |
| 6枚目 | 「お金のこと」参加費1,500円／当日、現金またはPayPay | 金額を一番大きく。支払い方法を2つのボタン風に |
| 7枚目 | 「当日の流れ（例）」受付 → ストレッチ・基礎練習 → シャッフルゲーム（試合）→ 片付け → 解散／※時間はイベントごとに主催者が当日お伝えします | 縦のタイムラインで5段階。横に実際のイベント写真を1枚（顔はぼかす）。下に「上手さより楽しさ重視」 |
| 8枚目（まとめ・CTA） | 「不安はこれで解決！」→「LINEで初参加ガイドを受け取る」／「11月の日程はプロフィールから」 | 青緑の背景にLINEの緑のボタン風。最後に「保存してね」 |

投稿文の案：

「1人で参加して浮かないかな…」「運動不足だけど大丈夫？」 はじめての方がよく気にすることを、8枚にまとめました📝

参加者の多くが1人参加・初心者です。上手さより楽しさ重視なので、気軽にのぞきに来てください🤝

📌 当日見返せるように保存がおすすめ 📩 公式LINEで『初参加ガイド』を受け取れます（プロフィールのリンクから）
